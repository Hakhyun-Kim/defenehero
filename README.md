# 🏰 용사 수학 디펜스 (DefenseHero) v2

| | |
|---|---|
| 🎮 **직접 플레이** | **https://hakhyun-kim.github.io/defenehero/** |
| 🎬 **데모 보기 (설치·조작 없이 바로)** | **https://hakhyun-kim.github.io/defenehero/?demo=expert** |

데모 링크를 열면 **AI가 알아서 플레이하는 것을 구경**할 수 있습니다. 게임 안에서는
🎬 데모 버튼이나 **D 키**로 언제든 켜고 끌 수 있어요.
`?demo=novice` / `?demo=normal` / `?demo=expert` 로 실력이 다른 플레이어를 볼 수 있습니다
(한글 `?demo=초보`·`?demo=보통`·`?demo=고수` 도 됩니다).

수학 문제를 풀수록 강해지는 어린이 3D 디펜스 게임입니다.
왼쪽의 **성**을 지키기 위해 용사를 소환·배치하고, **수학 문제(3~6학년)** 를 풀어
골드·소환 확률·조합 기회를 얻으세요. 성이 함락되면 리셋되지만, **별조각 ✨** 은 남아
영구 축복(메타 업그레이드)에 쓸 수 있어요.

> 그래픽·사운드·밸런스 방법론은 자매 프로젝트 dungeon100에서 가져왔습니다:
> 외부 에셋 0개(모든 그래픽/사운드를 코드로 생성), 순수 로직 분리, AI 봇 자동 밸런싱.

## 사운드 / 음악

음원 파일이 **0개**입니다 — 효과음 30여 종과 BGM 4트랙 전부를 Web Audio로 실시간 합성합니다.
BGM은 코드 진행(화성) · 패드 · 아르페지오 · 베이스 · 드럼(킥/스네어/하이햇) · 리버브를 갖춘
16분음표 스텝 시퀀서이고, 상황에 따라 트랙이 바뀝니다:

| 트랙 | 상황 | 분위기 |
|------|------|--------|
| prep | 웨이브 준비 | Am7-Fmaj7-C-Gsus4 · 따뜻한 왈츠풍 |
| battle | 전투 | Am-F-G-Am · 몰아치는 칩튠 (웨이브마다 템포↑) |
| midboss | 중간보스 | Am-A♯dim-Am-Gm · 불안한 반음 진행 |
| boss | 대보스 | Dm-B♭-C-Dm · 질주하는 오스티나토 |

외부 음원을 쓰지 않으므로 **라이선스 문제가 원천적으로 없고**, 파일 다운로드도 없습니다.

## 배경 — 바닷가 성, 그리고 저물어 가는 하루

이미지 파일도 **0개**입니다. 배경은 전부 셰이더로 만듭니다 —
실제 3D 자연은 [`src/nature.js`](src/nature.js), 그려 넣은 하늘은 [`src/sky.js`](src/sky.js).

| | |
|---|---|
| 🌾 **바람 잔디** | 인스턴스 풀잎 최대 14,000장. 정점 셰이더가 넓게 지나가는 돌풍과 잎마다 다른 잔떨림을 겹쳐 흔듭니다. 보스가 오면 바람이 사나워집니다. |
| 🌊 **바닷가** | 성 뒤가 바로 물가입니다. 파도는 프래그먼트에서 높이장을 해석적으로 미분해 법선만 만들고(프레넬 · 윤슬 · 백파), 물가 선은 노이즈로 흔들어 밀려왔다 빠집니다. |
| 🌌 **하늘** | 화면 위쪽 19%가 하늘입니다. 그라데이션 · 흐르는 구름 · 해와 후광 · **위상이 변하는 달** · 별과 은하수 · 그리고 성 위에 뜬 **거대 행성**(대륙이 도는 게 보입니다). |
| 🌅 **시간대** | 웨이브가 지날수록 아침 → 한낮 → 황금빛 → 노을 → 밤. 태양 각도·색, 안개, 물빛, 잔디 색, 하늘이 함께 움직입니다. 13웨이브에 깊은 밤에 닿습니다. |
| ✨ **반딧불이** | 밤에만 켜집니다. 길 위는 피해 앉으므로 몬스터를 가리지 않습니다. |

**밤이 오는 건 연출이면서 진행도 표시입니다** — 하늘이 어두워지고 달이 차오를수록
오래 버텼다는 뜻입니다. 다만 밤 조명은 "달빛이 밝은 밤"으로 잡았습니다.
아이들이 몬스터와 발판을 못 보면 분위기가 게임을 이겨 버리기 때문입니다.

> **하늘은 3D가 아니라 그려 넣은 배경입니다.** 이 카메라는 내려다보는 고정 시점이라
> 진짜 수평선이 화면 위로 벗어나 있어서, 하늘 돔을 씌워도 한 픽셀도 안 보입니다.
> 그래서 카메라에 붙인 쿼드 하나로 위쪽 19%를 떼어 하늘을 그립니다.
>
> 관건은 하늘을 그리는 게 아니라 **이음매를 지우는 것**이었습니다. 밴드 아래쪽 색과
> 먼 바다가 수렴하는 색을 같은 값(안개색)으로 맞추고, 보이는 바다가 거리 29.7~39.7
> 구간이라는 걸 실제로 재서 마지막 6유닛에서만 녹이도록 잡았습니다.
> 하늘을 얻은 대가로 전장은 조금 작아졌습니다 — 시야각을 넓히고 시선을 올려
> 성 깃대부터 스폰 포탈까지가 밴드 아래에 들어오게 맞췄습니다.

## 데모 모드 — AI가 실제로 플레이합니다

시연용 각본을 따로 만들지 않았습니다. 이 저장소에는 이미 난이도 검증용
**밸런스 봇**이 있고, 데모는 그 봇의 판단([`src/bot.js`](src/bot.js))을 그대로 씁니다.
그래서 데모는 정해진 장면을 재생하는 게 아니라 **매번 다르게, 진짜로 게임을 합니다** —
소환하고, 조합하려고 수학 문제를 풀고, 자리를 고르고, 성을 강화하고, 지면 다시 시작합니다.

| 켜는 법 | |
|---|---|
| 링크 | `?demo=expert` · `?demo=normal` · `?demo=novice` (한글 이름도 가능) |
| 버튼 | 오른쪽 위 🎬 데모 |
| 키보드 | **D** |

조작은 전부 사람이 쓰는 경로로 흘립니다(소환·배치·조합·문제 제출). 데모 전용
지름길을 만들면 "데모에서만 되는 버그"가 생기기 때문입니다. 덕분에 데모는
**살아 있는 회귀 테스트**이기도 합니다 — 어딘가 망가지면 데모가 먼저 멈춥니다.

| 프로필 | 수학 정답률 | 조합 | 성 강화 | 배치 |
|---|---|---|---|---|
| 초보 | 45% | 가끔 | 안 함 | 아무 데나 절반 |
| 보통 | 70% | 자주 | 수리만 | 대체로 좋은 자리 |
| 고수 | 90% | 항상 | 포탑·성벽까지 | 항상 최적 |

## 실행 방법

`index.html` 을 브라우저로 열면 바로 실행됩니다(이미 빌드된 `dist/game.js` 포함).

개발할 때:

```bash
npm install
npm run build     # src/ → dist/game.js 번들
npm run serve     # http://localhost:8642
```

```bash
npm run balance   # 난이도 밸런스 봇 (150판 × 3난이도 × 3실력)
```

밸런스 회귀 검증: `node scripts/balance-bot.mjs 120 check` — 기준선(`scripts/balance-baseline.json`)에서
중앙값이 ±3웨이브 이상 벗어나면 실패합니다.

URL 옵션: `?gfx=high|lite|min` 그래픽 강제, `?rafshim` 숨김 탭/자동화 환경용 타이머 구동.

## 게임 방법

| 구역 | 설명 |
|------|------|
| 3D 전장 | **성은 위쪽**, 몬스터는 아래 포탈에서 나와 **세 갈래 길**로 갈라져 성으로 행진 |
| 오른쪽 위 (항상 보임) | 골드·웨이브·소리, 🧮문제 학년, 🎲소환 버튼과 벤치 |
| 오른쪽 탭 | **⚗️조합 / 🏰성 / 🧍용사** — 한 번에 하나만 열려 화면 한 판에 다 들어와요 |

화면 높이에 맞춰 배치되고 목록만 탭 안에서 스크롤됩니다. 용사를 고르면 🧍용사 탭으로 갔다가
선택을 풀면(Esc·빈 곳 클릭) 보던 탭으로 돌아와요. 다른 탭에 있어도 조합할 수 있게 되면 🔴점이 뜹니다.
좁은 화면(1080px 미만)에서는 자동으로 한 줄 세로 배치로 바뀝니다.

가운데 길은 짧은 **지름길** — 몬스터가 덜 오지만 🐉보스가 이 길로 돌진합니다!

1. **소환** — 💰50. 기본 직업 4종만 나와요. 등급: 일반 → 희귀 → 영웅 → **전설(특수능력!)**
2. **배치** — 벤치 카드 클릭 → **길 옆의 돌 발판** 클릭. 사거리 원 표시.
   갈림길 옆 발판은 여러 길을 한번에 커버하는 명당!
   - **이동**: 배치된 용사를 **끌어다 놓으면** 회수 없이 옮겨져요
     (클릭으로 고른 뒤 빈 발판 클릭도 동일)
   - **🔀 자리 교환**: 용사를 고른 뒤 **다른 용사를 클릭하면** 서로 자리가 바뀝니다
     (끌어다 놓아도 같고, 키보드는 **←→로 상대 발판 선택 후 Enter**).
     근접 용사가 뒤에, 궁수가 앞에 서 있을 때 한 번에 바로잡는 조작이에요.
     고르면 빈 발판은 🟩초록, 다른 용사 자리는 🟦파랑으로 빛나요.
     *다른 용사의 정보만 보고 싶으면 마우스를 올려 툴팁으로 확인하세요.*
   - 배치·이동·교환이 **끝나면 선택이 저절로 풀립니다** — 이어서 다른 곳을 눌러도
     방금 그 용사가 따라 움직이지 않아요
   - **회수**: 용사를 **우클릭**하면 바로 벤치로 (R키도 가능)
   - 배치된 용사도 **그대로 강화·조합 재료**로 쓸 수 있어요 — 회수할 일이 거의 없어요
3. **수학** — 문제는 **조합할 때만** 나옵니다(따로 풀 필요 없음).
   학년(3~6)은 **무엇을 묻는가**(교과 범위), 난이도(⭐~⭐⭐⭐⭐⭐)는 **얼마나 조이는가**를 정해요.

   **★ 난이도는 "지금 만들려는 용사"가 정합니다** — 셀수록 문제도 셉니다:
   | 조합 | 난이도 |
   |------|--------|
   | ⬆ 희귀 등급업 | ⭐ 쉬움 |
   | ⬆ 영웅 등급업 / ✨ 특수(희귀) | ⭐⭐ 보통 |
   | ⬆ 전설 등급업 / ✨ 특수(영웅) | ⭐⭐⭐ 어려움 |
   | ✨ 특수(전설) | ⭐⭐⭐⭐ 고난도 |
   | 🌌 **신화 조합** | ⭐⭐⭐⭐⭐ 극한 · **2문제 연속** |

   같은 학년 안에서도 난이도가 오르면 **수가 커지고 연산 단계가 늘고 새 유형이 해금**돼요
   (예: 3학년 ⭐ `47 + 32` → ⭐⭐⭐⭐⭐ `⬜ × 7 = 231`).
   조합 목록의 ⭐ 배지로 **누르기 전에** 난이도를 미리 볼 수 있어요.

   **🎰 문제는 룰렛으로 뽑힙니다** ★ 이 게임 수학의 핵심
   조합 버튼을 누르면 문제가 곧장 나오지 않고 **세 장**이 펼쳐집니다.
   각 장에는 난이도 · **문제 유형 이름** · 제한 시간 · 받게 될 환급이 적혀 있고,
   불빛이 세 장 위를 돌다가 **뿅** 하고 하나에서 멈춰요. 걸린 문제를 풉니다.

   | | 난이도 | 환급 | 확률 | 덤 |
   |---|---|---|---|---|
   | 🟢 순한 문제 | 한 칸 아래 | ×0.5 | 20~35% | — |
   | 🔵 보통 문제 | 그 조합의 난이도 | ×1.0 | 45~50% | — |
   | 🔴 센 문제 | 한 칸 위 | ×1.55 | 15~35% | ⭐⭐⭐⭐ 이상이면 ✨**별조각 +1**|

   관문이 셀수록 🔴가 귀해집니다(신화 관문에선 15%) — 거기선 🔴가 lv6 + **2문제 연속**이라
   매번 걸리면 벌칙이 되니까요. 반대로 초반 관문은 🔴가 걸려도 부담이 없어서 넉넉히 줍니다.
   뽑는 동안 **시계는 멈춰 있고**, 아무 키나 누르면 결과로 건너뜁니다.

   > **왜 고르게 하지 않나** 한동안은 세 장 중에서 **골라서** 풀게 했습니다.
   > 난이도 보정을 푸는 사람 손에 넘긴다는 뜻이었는데, 조합이 연쇄로 이어지다 보니
   > 한 판에 열댓 번 같은 메뉴를 넘기는 일이 됐어요 — 선택이 재미가 아니라 **짐**이 됐습니다.
   > 난이도가 어긋나던 진짜 원인(하한선 없음 · lv이 수의 크기를 안 건드림)은 이미 생성기
   > 쪽에서 고쳤고, 사람마다 다른 편차는 아래 적응형 보정이 알아서 맞춥니다.
   > 그래서 선택은 지우고 **변덕**만 남겼어요. 결정 비용은 0, 긴장은 그대로.

   **⏳ 제한 시간은 문제 유형이 정합니다**
   `구구단 나눗셈` 18초 · `세 자리 × 두 자리` 62초 처럼, 그 유형을 푸는 데 드는
   실제 계산 노동량이 시간을 정해요. 조합 등급이 시간을 정하던 예전 방식은
   `20의 10%는?` 같은 문제에 119초를 주기도 했습니다.

   **⚔️ 가끔 "지금 이 판"을 묻습니다** — ⚔️ 표시가 붙은 문제
   숫자를 지어내지 않고 **화면에 있는 값을 그대로** 읽어 와서 묻습니다.
   배치된 용사의 공격력, 이번 웨이브에 실제로 나올 몬스터의 체력·마릿수, 남은 성 체력.

   > 👿 오우거 군주의 체력은 445예요. 🔮 희귀 마법사의 한 방은 39.
   > 몇 번 때려야 쓰러질까요? → **12**

   > 이번 웨이브 몬스터의 체력을 모두 더하면 10251이에요.
   > 지금 배치된 용사들의 초당 피해 합은 399. 정리하는 데 몇 초 걸릴까요? (올림) → **26**

   문제를 푸는 일이 곧 **판을 읽는 일**이 됩니다 — 두 번째 문제는 수학이면서
   동시에 "이 웨이브 감당되나?"라는 전술 판단이에요. 준비 단계에 용사가 배치돼
   있어야 낼 수 있으니, 낼 수 없는 상황이면 조용히 평범한 계산 문제로 돌아갑니다.

   지키는 규칙이 셋 있습니다: ① 적힌 숫자는 **엔진이 실제로 쓰는 값**이어야 하고
   ② 정답은 **적힌 숫자만으로 손으로 계산**돼야 하며(시뮬레이션을 돌려야만 아는 답은
   찍기와 같습니다) ③ 문제를 낸다고 **게임 상태가 바뀌어선 안 됩니다**.
   셋 다 눈으로는 안 보이므로 `npm run math:check`가 실제 웨이브를 돌려 대조합니다.

   **🎚 난이도가 알아서 따라옵니다**
   최근 8문제를 **한 번에·힌트 없이** 맞힌 비율이 85% 이상이면 룰렛에 올라가는 세 장이
   통째로 한 칸 올라가고, 40% 이하면 한 칸 내려갑니다. 바뀔 때는 뽑기 화면에
   `🔥 요즘 척척 맞히고 있어요 — 문제가 한 칸 올라갔어요!` 라고 **반드시 말해 줍니다**
   (말없이 조이면 아이는 자기가 못한다고 생각해요).

   **긴장 장치**
   - ⏳ **제한 시간** — 전투는 멈춰도 시계는 흘러요. 30% 남으면 바가 빨갛게 뛰고 째깍 소리가 나요.
     시간 초과는 오답 처리(정답 공개 후 재도전 가능) — 조합이 날아가진 않지만 환급과 연승은 사라져요
   - ⚡ **속도 보너스** — 빨리 맞힐수록 환급 최대 **+60%**
   - 🎯 **걸린 문제** — 센 문제가 걸릴수록 환급 배수가 커져요 (최대 ×2.4)
   - 🔥 **지혜 연승** — 한 번에 맞힌 문제가 연달아 쌓이면 환급 배수 최대 **×2** (틀리거나 힌트를 쓰면 리셋)
   - 🌌 **신화의 관문** — ⭐⭐⭐⭐⭐ 이상은 **2문제 연속 정답**. 하나라도 틀리면 **1단계부터 다시**

   기본 환급률은 학년이 정해요(3학년 15% … 6학년 45%). 💡 힌트는 💰30 (힌트를 쓰면 환급은 없어요)
   한 번 걸린 난이도는 그 관문이 끝날 때까지 유지돼요 — 틀려도 쉬운 문제로 바뀌지 않습니다.
4. **조합** ★ 강해지는 **유일한 길** (레벨 개념은 없습니다):
   - **⬆ 등급업**: 같은 직업·같은 등급 2명 → 등급 +1.
     비용 희귀 💰60 / 영웅 💰300 / 전설 💰1200 / 신화 💰2800. 가끔 🍀**럭키!** 두 등급 점프
   - **✨ 특수 조합**: 서로 다른 두 직업 → 특수 용사 6종.
     등급업과 규칙이 같습니다 — **같은 등급 2명끼리만**, 결과는 그 등급 +1.
     등급이 다른 용사는 재료로 아예 쓰이지 않아, 귀한 용사가 낮은 결과에
     갈려 사라지는 사고(전설+일반=희귀)가 원천적으로 없어요
   - **🌌 신화 조합**: **특수 2종** → 신화 용사 3종

   **⚠️ 등급 천장은 직업 세대로 정해집니다** (규칙 하나만 기억하세요):
   | 직업 | 최고 등급 |
   |------|-----------|
   | 기본 4종(⚔️🛡️🏹🔮) · 특수 6종(🗡️🌪️⚜️❄️🎯💫) | **전설** |
   | 신화 3종(⚡🌌😇) | **신화** |

   즉 **신화 등급은 신화 용사만** 될 수 있고, 신화 용사를 만드는 길은 두 가지입니다:
   ① **전설 특수 2종 조합** → 곧바로 신화 (예: 전설 마검사 + 전설 질풍검객 = **신화 검성**)
   ② **전설 신화용사 2명 등급업** → 신화 (예: 전설 검성 ×2 = **신화 검성**)
   *영웅 특수 2종을 합치면 **전설** 검성이 나옵니다 — 재료 등급이 결과 등급을 결정해요.*
   - **배치된 용사도 재료로 사용 가능** — 결과는 배치돼 있던 자리(둘 다면 더 높은 등급 쪽)에 자동 배치
   - **결과 캐릭터에 커서를 올리면 뭐가 나올지 미리 보여줍니다** (사거리·능력·초당 피해까지)
   - 영웅 이상 탄생 시 빛기둥·충격파·화면 플래시, 신화는 핑크 폭발로 축하해요 🎆
5. **성 관리** — 🔨수리 / 🧱성벽 강화 / 🗼마법 포탑(성이 스스로 공격, 3레벨)
6. **웨이브** — 몬스터는 **분대(3~7마리)로 몰려옵니다**. 분대별로 다른 길을 골라 진군하니
   한쪽만 막으면 뚫려요. 콤보 골드 배율도 노려 보세요.
   ⚠️ 용사 **판매는 손해**입니다(소환 50 → 판매 12). 함부로 사고팔지 말고 조합에 쓰세요!
   그래도 벤치가 넘칠 땐 벤치 아래 **💰 여러 명 판매**로 여럿을 골라 한 번에 팔 수 있어요
7. **함락되면** — 별조각 ✨ → 🌟**별의 축복**(영구 강화)에 투자 → 재도전!
8. **저장은 두 겹** — ① **자동 저장**: 웨이브가 끝날 때마다 준비 단계 스냅샷이 브라우저에
   저절로 남고(연출 프레임을 막지 않게 한가할 때 씁니다), 게임을 다시 열면
   **⏩ 이어하기 / 🆕 처음부터** 메뉴가 떠요. 성이 함락되면 자동 저장은 지워집니다.
   ② **💾 파일 저장 / 📂 불러오기**: 오른쪽 위 💾를 누르면 이번 판이 **JSON 파일 하나**로
   내려받아지고, 📂로 그 파일을 열면 이어서 합니다(백업·PC 간 이동용). 저장은 모두
   **웨이브 준비 단계의 스냅샷**이라 전투 중에는 저장되지 않아요
   (별조각·최고 기록은 원래 브라우저에 자동 저장됩니다)

### 🎯 사거리 vs 필살기 — 짧으면 확실한 기술로 보상

사거리는 벤치 카드에 **색으로 등급 표시**(🔴근접 🟠중거리 🟢장거리 🔵초장거리)되고,
카드나 배치된 용사에 **마우스를 올리면 상세 툴팁**(사거리 바, 초당 피해, 모든 능력)이 뜹니다.

| 직업 | 사거리 | 필살기 |
|------|--------|--------|
| ⚔️ 검사 | 100 🔴 | **💥치명타 30% · 2.5배** — 짧은 사거리 대신 압도적 한 방 |
| 🛡️ 수호병 | 105 🔴 | **🛡️방패 장벽**: 5.5초마다 사거리 안 적을 **1.3초 완전 정지** + 45% 감속 |
| 🏹 궁수 | 200 🟢 | 빠른 연사 |
| 🔮 마법사 | 155 🟠 | 범위 폭발 |

**방패 장벽**은 킹덤러시의 병영 길막에서 가져온 개념입니다 — 굽이길에 세우면 한 번에
**최대 7마리를 멈춰** 뒤쪽 궁수·마법사가 마음껏 두들깁니다. 단 보스는 정지에 강하게
저항(35%)하고, 한 번 멈춘 적은 2.6초 면역이라 수호병을 겹쳐 영구 정지시킬 수는 없어요.

⭐ **전설 능력**: 검사 **회전베기**(사거리 안 전부 + 치명타 40%·3배) · 수호병 **서리 결계**
(상시 감속 + 장벽 4초마다 1.9초) · 궁수 **관통 화살**(3명) · 마법사 **화염 폭발**(1.5배 + 화상)

### 🌳 3세대 조합 트리

```
기본 4종 (소환)  ──┐
                  ├─→ 특수 6종 (2세대) ──┐
기본 4종 (소환)  ──┘                    ├─→ 신화 3종 (3세대·최강)
                     특수 6종 (2세대) ──┘
```

레벨 노가다 대신 **조합만으로 성장**합니다. 등급업은 전설에서 멈추고,
**신화 등급은 3세대 조합으로만** 도달할 수 있어 후반에도 확실한 목표가 남습니다.

| 신화 레시피 | 신화 용사 | 사거리 | 능력 |
|-------------|-----------|--------|------|
| 🗡️마검사 + 🌪️질풍검객 | ⚡ **검성** | 115 🔴 | 사거리 안 전체를 2번씩 베고 불태움 + 치명타 35% |
| ❄️빙결사 + 💫정령궁수 | 🌌 **대마도사** | 205 🟢 | 거대 폭발(반경 95)로 얼리고 불태움 |
| ⚜️성기사 + 🎯파수꾼 | 😇 **수호천사** | 250 🔵 | 초장거리 저격 + 방패 장벽 + 처치마다 성 회복 |

## 난이도 설계 (밸런스 봇 검증)

가상 플레이어(초보/보통/고수)로 수백 판을 자동 시뮬레이션해 조정했습니다.
봇은 각 발판이 세 갈래 길을 사거리로 덮는 **가중 커버리지**를 계산해 배치하고,
높은 등급 조합을 우선 사용합니다(골드가 될 때만).
보통 난이도 기준 도달 웨이브 중앙값: **초보 8 / 보통 10 / 고수 30**.
고수 분포는 **신화 도달 여부로 갈리는 이봉형**입니다 — 신화를 만들면 30웨이브대까지,
못 만들면 10웨이브 전후. 그게 조합에 몰입할 이유가 됩니다(40웨이브 완주는 0%).
(12웨이브 이후 몬스터 체력이 가속해 장기전만 조입니다 — 초반 난이도는 보존)
후반에는 성이 받는 피해가 가속(threat ramp)되어 무한 스노볼을 막습니다.

동시 등장 몬스터(중반 방어 기준): 웨이브 5에 최대 11마리, 8에 20마리, 12에 31마리.

```bash
node scripts/diag-density.mjs   # 웨이브별 스폰 밀집도 진단
node scripts/diag-economy.mjs   # 전설/특수 용사 획득 난이도 진단
```
